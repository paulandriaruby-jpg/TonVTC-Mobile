# TonVTC Mobile

Applications Flutter de TonVTC.

| Dossier | Contenu |
| --- | --- |
| `gs-vtc-client/` | App client : réservation, paiement, suivi des courses |
| `gs-vtc-driver/` | App chauffeur : courses proposées, déroulé de la course, gains, recrutement |

L'API et le site sont dans le dépôt `TonVTC`. Les fichiers Firebase (`google-services.json`,
`GoogleService-Info.plist`) ne sont jamais commités.
